# 测试

## 自动化测试

```powershell
npm test
node --test installer/tests/*.test.mjs
python -m unittest discover -s installer/tests -p test_process_owner.py -v
```

该命令执行源码语法检查和 tests/ 下的测试文件，覆盖以下模块：

- SSE 流式传输、错误分类与请求取消。
- token 用量统计。
- 音频分段、播放队列及错误恢复。
- 课程任务、学习账本与跨课证据。
- 记忆相关性、上下文预算与调用方数量限制。
- 翻译校对和元数据处理。
- 安装下载校验、重试续传、解压边界和原生进程生命周期。

测试使用合成数据和本地模拟接口，不依赖真实 API 密钥。测试产物位于 work/，不应提交到仓库。

## 环境检查

```powershell
npm run doctor
```

检查 Python 依赖及模型文件。模型缺失时按 [安装指南](SETUP.md) 配置后重试。

## 集成测试

修改语音、浏览器或存储链路后，建议检查：

1. 录音、编辑、发送和删除。
2. 语音播放、重播和浏览器权限提示。
3. 课程归档、页面刷新和服务重启后的恢复。
4. 标签页之间的会话隔离。
5. 记忆纠正、删除和过期处理。
6. 桌面与窄屏布局。

使用独立数据目录，避免覆盖正常学习记录。

安装副本的本地语音与模拟接口检查、Windows Sandbox 入口见 [Windows 安装版](WINDOWS_INSTALLER.md)。这些检查不调用付费文本模型，也不读取已有用户档案。

## 真实模型测试

真实模型测试可能产生费用，应显式配置测试账号、数据集和预算。记录模型版本、硬件、网络条件和预热状态；响应速度、语言质量与教学效果分别评估。

公开测试数据应使用合成或获授权的内容，不应包含密钥、私人聊天、录音或个人记忆。

## 浏览器退出与后台归属

主页面和设置页面使用同源 WebSocket 标识当前打开的页面。最后一个页面关闭后约五秒退出；刷新和页面切换有重连宽限期，后台标签页不会按客户端定时器过期。原生安装版使用专属进程组，识别工作进程另外验证其所属服务，避免残留或误关其他程序。

配置 EMILIA_PLAYWRIGHT_MODULE 和 EMILIA_BROWSER_EXECUTABLE 后，npm test 与原生测试会执行无窗口浏览器验收；GitHub Actions 自动准备这些测试依赖，不下载模型或调用付费模型。

安装器保留 POST 流式连接供 API 自动化验收使用；浏览器页面使用独立 WebSocket，避免多页面占用 HTTP 请求连接池。
