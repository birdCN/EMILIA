EMILIA 使用说明
版本：1.3.4
许可证：MIT

一、简介

EMILIA 是一款在本机运行的英语口语练习应用。
通过语音或文字进行日常交流，也可以进入课程，完成练习和复习。

二、功能

1. 英语录音识别：录音结束后生成文字，可编辑后再发送。
2. 英语语音回复：使用本地 Kokoro 合成声音。
3. 表达反馈：检查语法，提供改写建议和中文翻译。
4. 课程训练：测评、课程计划、练习、迁移运用和总结。
5. 学习记录：维护学习重点、能力证据与间隔复习安排。
6. 记忆管理：查看、纠正和删除交流记忆及人物偏好。
7. 会话恢复：继续未结束的课堂或有效期内的临时聊天。
8. 模型配置：使用自己的服务商、模型和 API 密钥。

三、使用特点

语音练习、日常交流和课程训练集中在同一界面。
识别、默认语音合成和数据存储在本机运行。
语音与翻译、表达检查分开处理，减少等待。
模型、人物设定和头像资源可以按需配置。

四、安装要求

Windows 10/11 x64，Edge 或 Chrome 浏览器，麦克风。
首次安装需联网下载约 2.4 GB，预留至少 8 GB 空间，建议 16 GB 内存。
默认使用 CPU，语音识别速度取决于硬件；不需要预装 Node.js、Python 或 CUDA。

五、安装与启动

下载 EMILIA-1.3.4-Setup-x64.exe，双击安装。
选择安装目录，阅读并同意许可，等待运行环境和本地模型自动下载、校验。
Windows 提示安装 Microsoft 运行库时，允许安装。
安装完成后，从桌面或开始菜单打开 EMILIA。
关闭最后一个 EMILIA 页面后约 5 秒，相关服务和本次启动的语音后台会自动退出。刷新、页面跳转或只关闭其中一个 EMILIA 标签页不会误关。也可从托盘选择“退出 EMILIA”。
下载失败时重新运行安装程序，可以继续安装。
安装包未签名，请从可信发布页下载并核对 SHA-256。

六、首次配置

首次打开会显示配置引导。
选择服务商，填写自己的 API Key 和模型 ID，然后保存并进入练习。
保存设置本身不会调用收费接口；安装包不附账号、余额或密钥。
后续可在网页右上角“模型设置”修改，模型列表不可用时可手动填写模型 ID。
使用 Codex 通道需要本机安装并登录相应账号。

七、日常练习

直接输入英文并发送，或点击“开始说话”进行录音。
录音结束后检查识别文字，必要时修改，再确认发送。
回复可以重播。中文翻译可通过开关控制。
首次使用或长时间闲置后，本地模型需要预热。

八、课程与学习记录

进入测评或课程，按界面提示完成练习。
课堂结束后选择结束并归档，保存学习记录。
闲聊结束后，在“记忆”中选择“结束聊天并整理”。

在记忆面板可以查看、纠正或删除记录。
临时聊天恢复记录的有效期为 24 小时；继续或放弃由使用者选择。

九、模型费用与数据

云端文本模型会接收生成回复所需的对话上下文。
开场、回复、翻译、表达检查、备课、测评和记忆整理可能分别产生调用。
部分回复链路使用并发请求降低等待，取消请求不代表免费。
关闭中文翻译后，后续回复跳过译文生成；其他任务仍可能调用模型。
用量面板显示已报告的 token，最终费用以服务商账单为准。

安装版学习档案和加密设置位于 %LOCALAPPDATA%\EmiliaEnglishCoach\UserData。
下载缓存位于 %LOCALAPPDATA%\EmiliaEnglishCoach\DownloadCache。
卸载保留学习档案和设置；如需彻底删除，可退出后自行删除这些目录。
源码启动的数据默认位于 runtime/。不要上传安装目录、用户数据、录音和数据库。
API 密钥由 Windows 当前用户加密保存，不要粘贴到聊天内容中。

十、头像与人物设置

应用包含原有爱蜜莉亚人物画面、口型表情与动作脚本、卧室背景；桌面和开始菜单名称为 EMILIA，使用新生成的角色头像图标。
人物设定位于 teacher-persona.mjs，相关架构见 docs/ARCHITECTURE.md。
第三方模型、声音和角色素材遵守各自许可证。

十一、常见问题

页面能打开但没有声音：检查浏览器播放权限；退出后重开，或重新运行安装器修复模型。
无法识别录音：检查 ASR 模型、服务端口和计算设备配置。
模型连接失败：检查地址、模型权限、密钥和余额。
响应较慢：检查网络、模型服务状态、硬件占用和预热情况。

应用用于英语练习，反馈不属于官方雅思评分。
默认服务面向本机单用户；公网使用需要额外部署认证和用户隔离。
